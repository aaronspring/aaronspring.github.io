# aaronspring.github.io

Personal portfolio site for [Aaron Spring](https://aaronspring.github.io).

Built with [Astro Boilerplate](https://github.com/ixartz/Astro-boilerplate) (Astro v4, React, Tailwind CSS v3).

## Usage

https://aaronspring.goatcounter.com conforming to GPDR


## Development

```bash
npm install --legacy-peer-deps
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
